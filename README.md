# Mi Proyecto CSS

## Descripción
Este proyecto es una página web básica creada con HTML y CSS. Incluye una hoja de estilos externa (`styles.css`) que da estilo a títulos, párrafos y botones, incluyendo interacciones con la pseudo-clase `:hover`. El objetivo es practicar la separación de contenido y presentación, así como la publicación de un proyecto en GitHub Pages.

## Tecnologías utilizadas
- HTML5
- CSS3
- Git/GitHub
